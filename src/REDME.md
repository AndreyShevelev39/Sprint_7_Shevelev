# Проект по тестированию API Яндекс.Самокат (Sprint 7)

Автотесты для проверки API сервиса Яндекс.Самокат.

## Технологии
* **Java 11**
* **JUnit 4.13.2**
* **RestAssured**
* **Allure** (отчеты)
* **Lombok**
* **JavaFaker** (генерация данных)

## Запуск тестов
Для запуска всех тестов выполните команду:
`mvn clean test`

## Отчеты
Для генерации и просмотра Allure отчета:
`mvn allure:serve`
